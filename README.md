# 誤送信ガード for Gmail（Missend Guard）

Gmail の誤送信を「確認の手間を増やさずに」防ぐ Chrome 拡張機能（Manifest V3）。

[Gmail送信前チェッカー](https://github.com/waterada/chrome-ex-gmail)（waterada 氏）の思想を受け継ぎつつ、
ゼロから書き直した後継実装です（コードは全て新規のクリーンルーム実装・MIT ライセンス）。

## なぜ「毎回確認」では誤送信が減らないのか

従来の誤送信防止ツールは、送信のたびに全項目の確認を強制します。しかし毎回同じ確認を
繰り返すと人は内容を読まなくなり（**確認の形骸化**）、肝心の一回を素通ししてしまいます。
確認ダイアログそのものが誤送信の温床になるのです。

本拡張は逆の設計をとります。

- **正常な送信は一切妨げない** — 過去に確認済みの宛先だけなら、そのまま送信されます（小さな通知のみ）
- **異常があるときだけ止める** — ダイアログが出ること自体が「何かおかしい」のサイン
- **確認は各宛先につき一度だけ** — 確認した宛先は学習され、二度と聞かれません（外部宛先多数のときの BCC 提案のみ、漏えい防止のため毎回）

## 検知する異常（すべて設定でオン/オフ可能）

| 検知 | 防げる事故 |
|---|---|
| 初めて送信する宛先 | オートコンプリートの選び間違い・打ち間違い |
| 既知アドレス/ドメインとの酷似（編集距離） | 同姓の別人・`gmial.com` 等の typo ドメイン |
| **既知同士の取り違え**（普段の宛先と酷似・低頻度の別アドレス） | 学習済みの別人への誤送信（一度だけ確認） |
| **宛名ミスマッチ**（本文「佐藤様」なのに宛先に佐藤が居ない） | 宛先と内容の食い違い。異体字・ローマ字対応 |
| **スレッド宛先変化**（同じ件名の過去送信に居なかった宛先） | 返信・転送への意図しない相手の紛れ込み |
| 初めての「組織の組み合わせ」 | 別件の相手の紛れ込み（A社宛に B社を誤CC） |
| To/Cc に外部宛先が多数 | BCC忘れによるアドレス一斉漏えい |

Gmail 本体が持つ機能（添付忘れの検出・宛先ゼロのブロック・アップロード中の送信ブロック）や、
漏えいと無関係な注意（件名なし等）は**実装しません**。宛先の取り違えと漏えいだけに集中します。

「前に送ったことがある宛先だから素通り」では終わらせません。既知の宛先どうしの
取り違えも、頻度の非対称性・本文の宛名・スレッドの文脈という3つの角度から検知します。

さらに **自社ドメイン宛（From と同じドメイン）はチェック対象外**です。社内メールは
一切妨げません（Gmail などフリーメールのアカウントではこの除外は働きません）。

機能一覧はツールバーの拡張アイコンをクリックすると表示され、各機能を
ワンタップでオン/オフできます。

さらに、従来拡張の重大な穴だった **Ctrl+Enter / ⌘+Enter のキーボード送信もすべて横取り**します
（capture 段階でのイベント横取りのため、すり抜けはありません）。

## パフォーマンス

Chrome を重くしません。background（常駐プロセス）を持たず、`mail.google.com` 以外では
一切読み込まれず、待機中は DOM 監視もタイマーも使いません（イベント駆動のみ）。
注入コードは約 113KB・依存ライブラリゼロ。送信時の判定は実測 1ms 未満です。
ダイアログは Gmail のダークテーマに自動追従し、キーボードだけで完結します
（Tab 循環 / Space・Enter で確認 / Esc でキャンセル）。

## インストール（開発版）

1. このリポジトリを取得
2. `chrome://extensions` を開き「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で本ディレクトリを選択

## プライバシー

- 宛先履歴・設定は、この端末の `chrome.storage.local` に保存されます
- 既定では、圧縮した学習データ（**表示名は含みません**）を **ご自身の Google アカウントの
  Chrome 同期（`chrome.storage.sync`）** にもミラーし、同じアカウントの別端末と共有します
  （設定「端末間で同期する」でオフにできます）
- 開発者・第三者のサーバーへの送信は一切ありません（`permissions` は `storage` のみ）
- 詳細は [PRIVACY.md](PRIVACY.md)

## 開発

```
src/risk-engine.js    # 危険度判定（純粋ロジック・単体テスト対象）
src/gmail-dom.js      # Gmail DOM セレクタ層（多段フォールバック）
src/sync-codec.js     # 学習データの端末間同期用圧縮コーデック（表示名は同期しない）
src/history-store.js  # 宛先履歴の永続化
src/ui.js             # 確認ダイアログ / トースト（Shadow DOM）
src/content.js        # 送信イベントの横取りと制御
options/              # 設定画面
test/                 # 単体テスト + Gmail DOM 模擬ハーネス
docs/                 # 監査レポート・設計文書
```

- 単体テスト: `npm test`（node --test）
- 統合テスト: `test/harness.html` を任意の HTTP サーバーで開く（Gmail の DOM を模擬）
- パッケージ作成: `./package.sh` → `dist/missend-guard-<version>.zip`

## Gmail の DOM 変更への耐性

Gmail の難読化クラスに依存する箇所はすべて多段フォールバックになっています
（例: 送信ボタンはクラス `.aoO` → ツールチップの「(⌘Enter)」表記の順で探索）。
万一すべてのセレクタが外れても、**Gmail 自体の送信機能は一切壊れません**
（DOM を改変せず、イベントの横取りだけで実装しているため）。
宛先が読み取れない場合はフェイルセーフとして目視確認ダイアログを表示します。
